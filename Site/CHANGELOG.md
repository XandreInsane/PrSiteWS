# Journal des modifications

## V1.2
- Agrégation à la demande de trois sources : CROUS, ImmoJeune, Adele.
- Fiches d'origine et attribution de la source affichées dans les cartes ; pas de photos ou d'annonces de remplacement.
- Interface et sources complémentaires mises à jour pour différencier les connecteurs automatiques des recherches externes.
- Recherche depuis `file://` remplacée par un message explicite expliquant le déploiement serveur requis pour CORS.
- Limites de débit et d'attente sur les lectures HTML publiques ; les sources peuvent échouer indépendamment.
